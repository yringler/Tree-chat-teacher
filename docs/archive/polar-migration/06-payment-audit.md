## How it was verified

- **knip 5** (installed in the session scratchpad, nothing added to the repo), run from the repo root: `knip --include exports,types,files,nsExports,nsTypes,duplicates`. It reports one unused file in scope (`billing/vars.ts`) and the unused exports listed below. knip counts tests (vitest plugin), so "unused" means unused by `src` and `test`.
- Every knip hit was re-checked with `grep -rnw <symbol> apps packages scripts` (excluding `node_modules`, `apps/worker/site`) to split **dead** (no use anywhere, including its own file) from **only exported needlessly** (used in its own file).
- Field-level dead code (port fields, row columns) was checked by grepping the reads, e.g. `grep -rn "\.retryable" apps/worker/src` → none.
- Line numbers below are from `grep -n` on each file at `4e8a42d`.

## Rules for the executor

1. Do only the **SAFE-TRIM** items, batch by batch, in the order of §2. One commit per batch. Each batch must leave `pnpm typecheck`, `pnpm lint` (includes `scripts/check-provider-neutral.mjs`) and `pnpm test` green; the batch lists the suites that cover it, run those first.
