# Archive

These documents are historical. They record plans, research and decisions as they were written while the work was under way, up to the cleanup of October 2026: the original architecture plan (`PLAN.md`) and research notes (`RESEARCH.md`), the open pool's spec and plan (`pool/`), the move from Stripe to Polar (`polar-migration/`), and the append-only decision log that `docs/DECISIONS.md` replaced (`DECISIONS-2026-10.md`). Much of what they describe has since changed or been removed, so don't treat them as a description of the code, don't update them, and don't cite them from code comments. The current rules are in [DECISIONS.md](../DECISIONS.md), the setup in [operating.md](../operating.md) and [configuration.md](../configuration.md), and the history is in git.
